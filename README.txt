=========================================================
URDU PHONETIC WRITER - CHROME EXTENSION (MANIFEST V3)
=========================================================

How to Install in Google Chrome / Edge / Brave:
1. Extract (Unzip) this ZIP file into a folder on your computer.
2. Open Google Chrome and type this in the address bar:
   chrome://extensions
3. Turn ON "Developer mode" (top-right corner toggle).
4. Click "Load unpacked" (top-left button).
5. Select the extracted folder containing manifest.json.
6. Pin the "Urdu Phonetic Writer" extension from the puzzle icon in Chrome toolbar!

Features:
- Write Urdu directly using English keys (Phonetic layout: a -> ا, b -> ب, p -> پ, etc.)
- Works WITHOUT installing any Urdu keyboard in Windows/Mac
- One-click Copy & Paste buttons
- Clickable On-Screen Phonetic Keyboard with Shift key support
- Quick Islamic/Urdu greetings bar
- Auto-saves your text so it is never lost when closing the popup
